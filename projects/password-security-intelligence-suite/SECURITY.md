# Security Policy

## Reporting

If you discover a security issue, avoid publishing real credentials, tokens, or private data in a public issue. Provide a minimal synthetic reproduction instead.

## Data handling

The project is designed not to persist analyzed plaintext passwords. Contributors should preserve this property in code, tests, logs, exceptions, and telemetry.

## Scope

This is defensive educational software. Features that collect credentials, automate credential attacks, or exfiltrate secrets are out of scope.
